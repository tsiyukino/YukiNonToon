# Yuki NonToon Converter — 简体中文
ui.intro = 在构建模型时（进入 Play 或上传）把这个模型上的所有 lilToon 材质转换为 NonToon。不会修改你的材质和场景；删掉这个组件就回到 lilToon。
ui.nontoon_missing = 没有安装 NonToon。请从 lilxyzw 的 VPM 源（https://lilxyzw.github.io/vpm-repos/vpm.json）添加 NonToon 和 Shader Core。
ui.no_avatar = 这个组件必须放在模型里面（在它和它的父物体上都没找到 VRC Avatar Descriptor）。
ui.duplicate = 这个模型上有多个 Yuki NonToon Converter，只会使用第一个。
ui.settings = 设置
ui.convert_on_build = 构建时转换
ui.convert_on_build.tip = 关闭后保持 lilToon，不用删除组件。
ui.skip_android = 安卓 / Quest 保持 lilToon
ui.skip_android.tip = NonToon 不面向移动端，安卓和 iOS 构建时不转换。
ui.outline_mask = 描边粗细遮罩 → 顶点色
ui.outline_mask.tip = NonToon 只能用顶点色控制描边粗细。构建时把 lilToon 的描边粗细遮罩写进网格副本，例如避免眼睛周围出现描边。
ui.matcap_blur = 还原 MatCap 模糊
ui.matcap_blur.tip = lilToon 可以模糊 MatCap，NonToon 不行。会烘焙一张模糊版的 MatCap 贴图，避免反光显得锐利或油腻。
ui.shadow_brightness = 阴影亮度补偿
ui.shadow_brightness.tip = 在投影里 NonToon 只剩环境光，lilToon 只是着色变暗。如果脸和皮肤在阴影里太灰，可以调高。0 为关闭。
ui.preview_hint = 场景视图会通过 NDMF 预览实时显示 NonToon 的效果，可以在 NDMF 的预览设置里关掉。
ui.materials = 材质
ui.materials.hint = 查看每个 lilToon 材质如何对应到 NonToon。绿色：已转换；黄色：近似；红色：有功能丢失。
ui.analyze = 分析
ui.reanalyze = 刷新
ui.no_liltoon = 这个模型上没有 lilToon 材质。
ui.select = 定位
ui.keep_liltoon = 保持 lilToon
ui.overrides = 手动调整的值
ui.add_override = 添加手动调整…
ui.summary = 已转换 {0} 个，近似 {1} 个，有功能丢失 {2} 个。
ui.checks = 检查
ui.check_modules = 这些 NonToon 模块没有安装，对应的 lilToon 功能无法转换：{0}。请在 NonToon 的着色器设置里启用。
ui.check_receive_shadows = 「{0}」不接收阴影，被挡住时仍然是亮的（常见于脸部）。建议打开。
ui.fix = 修复
ui.export = 导出（可选）
ui.export.hint = 把转换后的材质、贴图和网格写入文件夹，并在场景里替换到这个模型上。只有想手动精调 NonToon 材质时才需要。再次导出会原地更新同一批文件。
ui.export.folder = 文件夹
ui.export.button = 导出并替换到模型
ui.export.confirm = 要把 NonToon 材质替换到场景里的「{0}」上并保存到 {1} 吗？这会修改模型（可以撤销）。
ui.export.done = 已导出 {0} 个材质到 {1}。
ui.ok = 确定
ui.cancel = 取消

feature.main3rd = 第 3 层已烘焙进底色
feature.main3rd_approx = 第 3 层已烘焙；UV 模式、仅左/右、动画或溶解等选项为近似

feature.normal = 法线贴图
feature.normal2 = 第 2 法线贴图 → Details
feature.module_missing = 没有安装 NonToon 模块「{0}」
feature.shadow = 阴影颜色和边界 → 阴影渐变（Ramp）
feature.shadow_sdf = 脸部 SDF 阴影遮罩 → NonToon SDF
feature.shadow_flat = 平面阴影遮罩类型为近似

feature.shadow_blurmask = 不支持阴影模糊遮罩

feature.backlight = 背光由 NonToon 处理，颜色和颜色贴图无法还原
